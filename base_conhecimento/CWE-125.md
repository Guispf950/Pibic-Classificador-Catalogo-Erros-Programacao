# CWE-125 — Leitura Fora dos Limites (Out-of-bounds Read)

## O que é
Acontece quando o programa **lê** um endereço **fora dos limites** válidos de um buffer. O
programa acaba usando um valor de memória vizinha que não faz parte do dado pretendido — um
lixo qualquer — o que leva a resultados errados ou a decisões baseadas em dados inválidos.

## Por que acontece em C
C **não verifica limites** na leitura. Ler `v[N]` num vetor de tamanho `N`, percorrer um vetor
até uma posição além do fim, ou ler uma string sem um terminador `'\0'` correto faz o programa
acessar bytes que estão logo depois do buffer. Ao contrário da escrita, a leitura não corrompe
o vizinho, mas **contamina** a lógica com um valor sem sentido.

## Como interpretar o que a ferramenta apontou
A ferramenta marca a operação de **leitura** inválida (READ), com o ponto do acesso (o
sintoma) e, quando dá, o bloco/tamanho envolvido. A causa é o índice ou a extensão lida
passarem do fim do dado válido.

## Princípio da correção (sem código)
Só leia posições **dentro** do intervalo válido (`0` a `tamanho − 1`). Revise as condições de
parada dos laços e garanta que strings tenham o terminador esperado antes de percorrê-las.
Perguntar "esse índice existe mesmo?" antes de ler evita usar lixo como se fosse dado.
